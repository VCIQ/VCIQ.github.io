如何记录审核

查看证据后选择接受或拒绝，导出决定 JSON。将文件放入私有 STATE 目录，再使用 review_cli decide 校验并以 --apply 应用。网页本身没有写入接口。刷新后可看到已记录状态。

若证据或队列已更新，旧请求会被拒绝，请重新同步和审核；不要修改指纹强行提交。

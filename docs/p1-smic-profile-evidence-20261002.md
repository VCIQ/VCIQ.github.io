# 中芯国际档案：文档门户误当技术资料的展示纠错

## 已核对的问题

本轮在公开公司档案回读中发现，核心技术栏显示了
`SMIC DOCUMENT DISTRIBUTION PLATFORM Documents and Downloads Login`。
仓库中保留的 `public/data/venture_profiles.json` 也包含该文字，
相应来源是 `http://service.smics.com/ddplatform/`，其 section 被写作 technology。
同一档案的产品列表还混入了文档分发和供应商入口，页面仍显示87%的完整度评分。

这些证据只足以确认资料提取误判，不足以补写公司的真实技术说明。
本轮未访问登录后的内容，没有请求任何登录凭证，也没有直接覆盖原始档案。

## 修复范围

- 在共用的公司档案读取层增加精确纠错：只匹配 smic 主体与上述门户来源。
- 混入门户标题的技术段落改为明确的待核验说明，不编造技术细节。
- 移除已观察到的、无独立来源的门户产品条目；保留原有晶圆和工艺产品记录。
- 原始来源链接、标题、来源级别均保留；在展示中标明其是服务入口，而非技术证据。
- 受影响档案不再沿用原完整度百分比，显示“技术资料及完整度评分待复核”。
- 不改动成立时间、团队、融资、上市身份或原资料更新时间。
- 若后续原始档案不再包含这些误判内容，不将它永久锁定为待复核状态。

此补丁是前端读取与展示纠错，不等于上游提取器已完成修复，
也不等于已经补齐公司的真实技术资料。原始档案保持不变，方便后续来源审计。

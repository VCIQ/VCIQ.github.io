## 审核规则
1. P0 优先：截图涉及「微容科技，IPO成功过会」（集微网）和「一天分析一家AI制药企业（6）：百图生科」（药智观察）。目前前者仅找到同媒体相关但不同标题报道，后者还没有得到可靠原微信链接。
2. 微信原文须真实 `mp.weixin.qq.com` 分享短链或 `__biz+mid+idx` 完整长链，并进一步检查**页面可打开、真实公众号、同篇标题与日期**；结构合法本身不代表已经核验。
3. 其他官网/媒体/政府网站只能列为 `non-wechat-alternative`。如拟采用，必须同步纠正平台、来源、事实证据等级，不能保留「微信原文」标签而偷换 URL。
4. 不更改 `public/data/articles.json`，它是自动生成数据；正式修复应追溯上游持久化的数据源/映射，以免下一轮刷新反复出现旧签名 URL。
5. 无法证实的仍保留「原文链接待更新」并列入待核验。不得取消安全保护、猜测微信文章 ID 或使用过期签名导航链接冒充稳定原文。
6. 所有 `alternativeCandidates` 均 `reviewStatus=pending`、`approvedForReplacement=false`；人工批准前不改变生产环境、Shadow stop 或站点发布。
